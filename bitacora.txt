13. FLEXBOX VS. GRID

Grid: portada, galeria, reservas 2:1 y fila de campos (columnas alineadas).
Flexbox: encabezado y pie (distribucion en un eje y cambio de direccion).
Los div de portada, flota, rutas y fila de campos son contenedores estructurales.

24. BOOTSTRAP 5.3 Y TAILWIND CSS

Curva de aprendizaje: Bootstrap ofrece componentes y convenciones listas;
Tailwind requiere aprender y combinar utilidades.
Personalización: Bootstrap usa variables y componentes; Tailwind facilita
ajustes directos mediante utilidades y configuración del tema.
Tamaño final: el CDN de Bootstrap carga el CSS compartido aunque no se use todo;
Tailwind puede generar CSS reducido mediante compilación y eliminación de clases
no utilizadas.
Casos de uso: Bootstrap agiliza interfaces con componentes consistentes; Tailwind
favorece diseños a medida con un proceso de compilación. Se mantiene Bootstrap
5.3 para conservar la implementación CDN existente y evitar añadir Node.js/CLI.
